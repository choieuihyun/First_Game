## 지금 단계

**포식과 신체까지 구현 완료.** 사람의 플레이 확인은 한 번도 없었다 (사용자가 플레이할 수 없는 상황).

- 정체성 (D27): 마법 테마와 먹어치워 흡수하는 것이 메인. 화학 반응은 바탕 규칙. "화학 반응 서바이버" 라고 부르지 않는다
- 본 게임: SampleScene 에서 Play 하면 `Game.App.GameBootstrap` 이 스스로 뜬다 (씬은 건드리지 않음)
- 들어 있는 것: 늪지 맵, 몸 종류 3 (뿔형, 포자형, 점액형) x 물질 4, 포식 게이지, 부위 3곳 (왼팔, 오른팔, 꼬리) 과 부위별 조준, 강화 5단계, 반응 3종. 상세는 `시스템/포식/SYSTEM.md`
- 조작: 끌어서 이동 (또는 WASD). 부위 고르기는 화면 버튼 또는 숫자키 1 왼팔, 2 오른팔, 3 꼬리, X 버리기. 죽은 뒤 다시 시작은 버튼 또는 R
- 검증 (2026-11-16): 포식과 신체 구현 직후 `Tools/verify.sh all` 통과 (규칙 테스트 116개, Unity 컴파일, PlayMode 테스트 6개), 스크린샷으로 몸과 적이 그려지는 것 확인. 옛 시제품 삭제 뒤에도 다시 통과
- 다른 AI 의 전체 코드 검토는 전장 반응까지만 받았다 (D21). 포식과 신체는 검토를 받지 않았다
- AI 가 확인하지 못한 것: 재미와 손맛, 실제 터치와 마우스로 버튼이 눌리는지, 화면 글자 (한글 깨짐), 안드로이드 기기 동작
- 원격 저장소: https://github.com/choieuihyun/First_Game (첫 커밋은 전장 반응까지. 포식과 신체는 아직 커밋하지 않았다)
- 옛 시제품 `Assets/Prototype/` 은 삭제했다 (첫 커밋에 남아 있어 되살릴 수 있다)

## 다음 할 일

1. 사용자가 시키면 포식과 신체를 커밋 (지금은 커밋하지 않은 상태)
2. **내용 늘리기 기획 (`/design`)**: 사용자 의견 "엄청나게 다양한 조합이 있어야 재미를 느낀다". 지금은 반응 3개뿐이라 조합 폭이 좁다
   - AI 제안 규모 (사용자 답 없음): 물질 8~10, 반응 20~30, 몸 종류 5~6
   - 반응 결과의 종류를 늘려야 한다 (얼리기, 미끄러뜨리기, 번지며 타기, 방어 녹이기, 밀어내기 등). 효과 조각 코드 추가 필요 (상태 부여 등)
   - 방식 종류 추가 (광선, 고리 등) 는 코드 필요. 강화 단계별 동작 변화도 후보
3. 사용자가 Unity 에서 Play 로 확인 (Game 창 비율 세로 9:16), 소감을 `플레이테스트/` 에 기록
4. 그 밖의 후보: 두 번째 맵과 맵 선택, 촉매, 판 사이 성장, 이어하기 화면, 정식 그림과 UI, 안드로이드 빌드

## 미룬 지적 (코드 검토에서 나온 사소한 것)

- 젖은 적이 물웅덩이를 지나면 원래 지닌 물이 6초짜리로 바뀐다
- 같은 틱에 죽은 적이 뒤따르는 탄을 먹는다
- 지형 웅덩이는 반응하면 영영 사라진다 (기획 결정 필요)
- 일시정지 신호 둘 (앱 멈춤, 포커스) 이 서로 덮어쓴다. 일시정지 때 끌기 상태를 초기화하지 않는다
- 한 프레임에 2틱이 돌면 보간이 어긋난다. 목표 프레임 수를 지정하지 않았다 (기기 빌드 때 필요)
- 화면 쪽에서 매 프레임 색 파싱과 문자열 할당이 있다
- HUD 가 세트 3개와 세로 화면에 맞춰 박혀 있다. 노치 처리가 없다
- 저장 복원 시 값 범위와 데이터 버전 검사가 없다 (이어하기 화면을 만들 때 필요)
- `verify.sh` 가 Unity 를 못 찾으면 옛 로그를 읽을 수 있다
- damage, apply_substance 효과 조각은 쓰는 반응이 없어 테스트가 없다
