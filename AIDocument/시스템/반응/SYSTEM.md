## 2. 규칙

**물질이 있는 곳:** 적에게 묻은 물질, 전장의 영역 (구름, 장판, 지형 웅덩이), 날아가는 탄.

**물질 규칙 (D16):**
- 대상 하나에 물질 하나만
- 반응하면 두 물질 모두 사라진다. 결과물은 새로 생긴다
- 반응하지 않는 물질이 적에게 닿으면 덮어쓴다. 영역은 바뀌지 않는다
- 적에게 묻은 물질은 시간이 지나면 사라진다. 적이 원래 지닌 물질과 지형은 반응할 때까지 남는다

**접촉이 일어나는 경우:**
- 탄이 적에 맞음 (적이 먼저다. 여러 적에 걸치면 먼저 생긴 적 하나)
- 탄이 영역에 들어감 (반응하면 탄과 영역이 사라지고, 아니면 통과)
- 영역 안에 적이 있음 (접촉 간격마다 한 번. 영역의 피해도 이때 들어간다)
- 영역끼리 겹침 (접촉 간격마다 한 번)
- 폭발이 물질을 지녔으면 반경 안의 적과 영역에 그 물질이 닿은 것으로 처리 (연쇄가 여기서 이어진다)

**지금 있는 반응:** 23개. 목록과 성격은 `기획/2026-11-16_내용_확장.md` 4절, 정확한 값은 `reactions.csv` 와 `effects.csv`.

**상태:** 반응은 적에게 상태를 걸 수 있다. 같은 상태가 다시 걸리면 남은 시간은 긴 쪽, 세기는 센 쪽을 따른다.

| 상태 | 효과 |
|---|---|
| freeze | 움직이지도 공격하지도 못한다 |
| slow | 속도가 amount 배가 된다 (0.4 면 40% 속도) |
| dot | 초당 amount 의 피해 |
| vulnerable | 받는 모든 피해가 amount 배가 된다 |

**연쇄 한도:** 반응으로 생긴 물질은 연쇄 단계를 물려받는다 (마법, 지형, 적이 원래 지닌 것은 0). 반응의 단계는 두 물질 중 큰 쪽 + 1 이고, 한도를 넘으면 반응하지 않는다.

**틱당 상한:** 반응은 큐에 쌓였다가 틱 끝에 앞에서부터 처리한다. 한 틱 상한을 넘으면 다음 틱으로 넘긴다.

폭발과 감전은 플레이어에게 피해를 주지 않는다.

## 3. 조정 가능한 수치

| 수치 | 현재 값 | 의미 | 바꾸는 곳 |
|---|---|---|---|
| 물질 지속 시간 | 불 3, 물 6, 독가스 4, 번개 0.5, 얼음 5, 기름 8, 산 5, 쇳가루 8, 수소 4, 증기 3 | 적에게 묻어 있는 시간 (초) | `Assets/Resources/Data/substances.csv` 의 duration |
| 물질 색과 모양 | | 화면 표시. 모양은 물질끼리 겹치면 안 된다 | `substances.csv` 의 color, shape |
| 반응 결과 | 위 표 | 피해, 반경, 횟수, 남기는 물질 | `effects.csv` |
| 어떤 물질끼리 반응하나 | 위 표 | | `reactions.csv` |
| chain_depth_limit | 4 | 연쇄 단계 한도 | `balance.csv` |
| contact_interval | 0.5 | 계속 닿아 있을 때 반응 간격 (초) | `balance.csv` |
| max_reactions_per_tick | 20 | 한 틱에 처리하는 반응 수 | `balance.csv` |

### 새 반응을 추가하는 방법 (코드 수정 없음)

1. 새 물질이 필요하면 `substances.csv` 에 한 행 (모양은 다른 물질과 겹치지 않게. 적에게서 흡수할 수 있는 물질이면 rune 을 true 로 하고, `stages.csv` 의 absorb 와 enemies 에 추가)
2. `effects.csv` 에 결과를 적는다. 같은 effect 이름으로 여러 행을 쓰면 order 순서대로 실행된다
3. `reactions.csv` 에 한 행: 만나는 두 물질과 effect 이름
4. `Tools/verify.sh core` 를 돌린다. 틀린 곳이 있으면 파일과 행을 짚어 준다

효과 조각 (`effects.csv` 의 piece):

| piece | 하는 일 | 쓰는 열 |
|---|---|---|
| damage | 반응이 일어난 적에게 피해 | amount |
| apply_substance | 반응이 일어난 적에게 물질을 묻힘 | substance |
| spawn_zone | 그 자리에 영역 생성 | substance, radius, duration, amount (접촉 간격마다 주는 피해, 비우면 0) |
| explode | 반경 안 모든 적에게 피해. substance 가 있으면 그 물질이 닿은 것으로 처리 | amount, radius, substance (선택) |
| chain | 가까운 적으로 차례로 옮겨 가며 피해 | amount, radius (한 번에 건너뛰는 거리), count (횟수) |
| status | 상태를 건다. radius 가 있으면 반경 안 전체, 없으면 반응이 일어난 적 하나 | status, amount, duration, radius (선택) |
| push | 반경 안의 적을 밀어낸다. amount 가 음수면 끌어당긴다 | amount (거리), radius |

모든 피해는 `Combat.Damage` 를 거친다. 약화 상태가 빠짐없이 적용되게 하기 위한 것이다. 새 피해 경로를 만들 때도 이것을 쓴다.

## 6. 주의사항

- 수치는 전부 처음 값이다 (AI 판단). 플레이로 조정한다
- 영역이 적과 반응하면 그 영역 전체가 사라진다 (D16 "반응하면 둘 다 사라진다"). 큰 구름이 적 하나 때문에 통째로 사라지는 것이 어색하면 기획을 다시 정해야 한다
- 수소 구름은 안에 들어온 적에게 수소를 묻힌다 (젖은 적의 물을 덮어쓴다)
- 지형 웅덩이도 반응하면 사라지고 다시 생기지 않는다. 판 후반에는 지형이 없을 수 있다 (기획 결정 필요)
- 젖은 적이 물웅덩이나 물 마법에 닿으면 원래 지닌 물이 6초짜리로 바뀐다 (알려진 문제)
- CSV 는 BOM 있는 UTF-8 이다. 엑셀에서 열어도 한글이 깨지지 않게 하기 위한 것. 테스트가 확인한다
- 느려짐, 약화, 중독은 화면에 표시가 없다. 얼어붙은 적만 얼음 껍질로 보인다
- 촉매는 아직 없다
