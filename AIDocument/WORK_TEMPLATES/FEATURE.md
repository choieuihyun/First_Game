# 기능 개발 작업 템플릿

---

## 작업 시작 시 기록

| 항목 | 내용 |
|---|---|
| 작업일 | YYYY-MM-DD |
| 시스템 | (무기 / 적 / 성장 / 웨이브 / UI 등) |
| 기능명 | |
| 근거 기획서 | `기획/YYYY-MM-DD_<주제>.md` |

### 요구사항 정리

```
기능 설명:

플레이 시나리오 (플레이어가 겪는 순서):
1.
2.
3.

영향 범위:
- 다른 시스템:
- 에디터 손작업 필요 여부: (있으면 사용자에게 단계별 안내)
- 새로 생기는 조정 수치:
```

### 기획 점검 (구현 전에 짚을 것)

- 극단 상황: 적이 아주 많을 때, 0 이 될 때, 최대치일 때
- 겹침: 같은 효과가 여러 개 겹치면 더해지나, 곱해지나, 하나만 적용되나
- 타이밍: 레벨업 선택 중, 사망 순간, 일시정지 중에 이 기능은 어떻게 되나
- 성능: 동시에 몇 개까지 생길 수 있나
